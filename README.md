# Calculadora Cientifica_DDAM

Aplicación móvil diseñada para facilitar la resolución de problemas matemáticos, desde operaciones
aritméticas básicas hasta cálculos más avanzados. Su interfaz permite al usuario ingresar expresiones matemáticas completas, incluyendo 
el uso de paréntesis y múltiples operadores simultáneos. Una vez ingresada la operación, la aplicación la evalúa respetando las reglas 
matemáticas y la jerarquía de los signos, proporcionando el resultado de manera rápida, precisa y con notificaciones en 
caso de ingresar operaciones inválidas.
